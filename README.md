# 📚 JudgeByTheCover

JudgeByTheCover is a Java Swing-based desktop application designed to help users discover, organize, and review books.

The application provides a simple and interactive interface where users can browse books by genre, search for books, manage their personal library, track reading progress, and share reviews and ratings.

---

## ✨ Features

### 🔐 User Login
- Simple username and password login interface
- Basic input validation

### 🔎 Book Search
- Search for books by title
- Displays matching books through an interactive interface

### 📚 Browse by Genre
Books can be explored through different genres:

- 📜 History
- 💡 Self-Help
- 🔍 Mystery
- 🚀 Sci-Fi
- 🧙 Fantasy
- 👻 Horror
- 💕 Romance
- 🔮 Future

### 🎲 Random Book Recommendation
- Discover a randomly selected book from the available collection.

### ❤️ Favorites
- Add books to your favorites.
- Remove books from favorites.
- View favorite books through My Library.

### 📌 Reading Status
Users can organize books according to their reading progress:

- 📖 To Be Read
- 📚 Currently Reading
- ✅ Finished

### ⭐ Ratings & 💬 Reviews
- Rate books from 1 to 5 stars.
- Add written reviews.
- View reviews from users.
- Automatically calculates the average rating.

### ❤️ My Library
A dedicated library section allows users to view books according to:

- Favorites
- To Be Read
- Currently Reading
- Finished

### 📊 Reading Dashboard
The dashboard provides an overview of the user's reading activity, including:

- Total books
- Favorite books
- Books to be read
- Currently reading
- Finished books
- Reading completion percentage
